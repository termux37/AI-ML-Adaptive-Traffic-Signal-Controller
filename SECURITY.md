# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Academic Simulation Scope
This repository is an academic simulation and algorithmic evaluation platform running on Eclipse SUMO. It is **not** certified for direct physical actuation on real-world municipal traffic controllers or municipal traffic controller hardware.

## Reporting a Vulnerability
If you discover a security vulnerability or critical issue in this repository:
1. Please do not open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories or contact the repository maintainers directly.
3. Include detailed steps to reproduce the issue and the potential impact.

We aim to acknowledge and address verified security issues promptly.
